### Summary

**Summary:**

The LPO (Listwise Policy Optimization) repository is the official implementation of a novel explicit target-projection framework for Reinforcement Learning with Verifiable Rewards (RLVR). The project aims to demystify the implicit target by restricting the proximal RL objective to the response simplex and then projecting the policy via exact divergence minimization. The implementation is built upon the verl framework and provides a Python-based solution for various reasoning tasks.

**Key innovations:**

LPO introduces a new approach to target-projection in RLVR by leveraging the response simplex of a large language model (LLM). This approach allows for more efficient and effective exploration of the policy space, making it a significant improvement over existing solutions. The use of exact divergence minimization also enables more precise control over the policy, leading to better performance.

It aims to reduce the computational cost of LLMs by consuming zero tokens outside final question answering. The project ships as a Rust crate, a CLI, and a Python module, providing an efficient memory management system for LLM agents.

**2. Key innovations**: What makes this project notable is its innovative approach to zero-token memory management. It uses a combination of entity-context graph, temporal hierarchy, and BM25 indexing to store and retrieve conversation turns efficiently. This allows the model to consume zero tokens outside final question answering, making it more computationally efficient.

1. **What it does**: Mentat is a two-layer coding agent that enables users to edit their code without exposing their repository to the cloud. It runs a local model to understand the request and repository, then builds a synthetic mirror of the project, which is sent to a large cloud model. The cloud model makes the change against the mirror, and the result is mapped back onto the original files with exact token substitution.

2. **Key innovations**: Mentat is notable for its use of a two-layer approach, where the local model processes the request and repository, and the cloud model performs the actual changes. This approach ensures that the user's repository and data never leave their machine. This is different from existing solutions that often rely on remote servers or cloud-based services to process requests.

3. **Tech stack**: Mentat uses TypeScript (97.6%), Python (1.8%), JavaScript (0.6%), and Node.js (npm) as its primary languages and frameworks. The project also utilizes a CI/CD pipeline for automated testing and deployment.

By keeping the user's repository and data on their machine, Mentat reduces the risk of sensitive information being exposed to the cloud. This could be particularly beneficial for organizations that require high levels of data security and confidentiality.

The `contextcraft` repository is an open-source project that aims to create a semantic codebase compressor for Large Language Models (LLMs). The primary language used is Python, with Jinja as a secondary dependency.

**Key Innovations**

ContextCraft is an AST-aware, dependency-graph-ranked, token-budgeted codebase compressor that uses a combination of techniques to optimize code. These innovations include:

* Personalized PageRank on the cross-file dependency graph to rank file importance
* Multiple-Choice Knapsack Problem (MCKP) solver to pack maximum architectural signal into a token budget
* Token-budgeted approach to handle the constraints of LLMs

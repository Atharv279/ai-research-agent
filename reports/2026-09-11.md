**Project Overview**

The `datapilot` repository is an AI-powered project management tool that utilizes natural language processing (NLP) to analyze and manipulate project data. The tool provides a user-friendly interface for managing projects, including CRUD operations, soft deletion, and auditing.

**Key Features**

* Agent architecture: Based on Tool Calling, where the model decides which tool to call without a fixed workflow
* Complete CRUD operations: All CRUD operations are performed through natural language input
* Soft deletion: Data is deleted, but remains available for 7 days before being automatically cleared
* State synchronization: Modifications to the project's status string trigger a recalculation of five boolean fields
* Auditing: All write operations are logged to `logs/audit.jsonl` for complete tracing
* Self-correction: SQL execution failures result in error messages that allow the model to automatically correct the issue

**Design Principles**

* Agent layer is thin, while the tool layer is thick. The model only handles decision-making, while the tools handle execution
* Ability is determined by the tool list, and the absence of a tool means the absence of an ability
* Confirmation mechanisms are external to the loop, allowing for cross-loop state management

**Reorganization and Improvements**

The project was initially structured using a workflow architecture, but was reorganized to use an Agent architecture. This change resulted in reduced code size, improved context handling, and simplified functionality.
